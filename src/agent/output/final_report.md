# 长鑫科技（688825）2026年半年度财报分析：现金流质量深度评估

## 核心摘要

2026年上半年，长鑫科技在全球DRAM供不应求、价格大幅上涨的行业景气周期中，实现了经营业绩与现金流质量的“双爆发”。报告期内，公司经营活动现金流量净额（CFO）高达1,311.56亿元，同比增长2,985.64%；净现比达1.69，营收现金含量达87.26%，各项现金流指标均处于制造业顶尖水平。分析表明，公司当前现金流具有极高的盈利含金量、强劲的内生造血能力和纯净的主营驱动特征，呈现出典型的半导体存储周期上行阶段“超级现金牛”属性。但需警惕行业周期性回落风险及高强度资本开支对未来自由现金流的潜在压制。

## 一、 现金流质量量化评估

### 1.1 核心财务数据概览

| 指标 | 2026H1 | 2025H1 | 同比变动 |
| :--- | :--- | :--- | :--- |
| 营业收入 | 1,503.10亿元 | 154.38亿元 | +873.64% |
| 归母净利润 | 776.05亿元 | -23.32亿元 | 扭亏为盈 |
| 扣非归母净利润 | 787.93亿元 | -23.87亿元 | 扭亏为盈 |
| 经营活动现金流量净额（CFO） | 1,311.56亿元 | 42.51亿元 | +2,985.64% |
| 总资产 | 4,680.78亿元 | 3,367.85亿元（上年末） | +38.98% |
| 归母净资产 | 1,347.22亿元 | 567.54亿元（上年末） | +137.38% |

### 1.2 现金流质量核心指标

#### （1）净现比（CFO / 归母净利润）：1.69
- **计算**：1,311.56亿元 / 776.05亿元 ≈ 1.69
- **解读**：该比率远超1.0的安全线，表明公司净利润有充足的现金流支撑，盈利含金量极高。作为重资产IDM厂商，巨额折旧摊销为非付现成本，在景气周期中CFO天然高于净利润。1.69的净现比不仅覆盖了折旧，还实现了大量现金回笼，在半导体周期上行阶段属于优异水平。
- **扣非验证**：CFO / 扣非净利润 = 1,311.56 / 787.93 ≈ 1.66，进一步确认现金流与主营业务利润的高度匹配。

#### （2）营收现金含量（CFO / 营业收入）：87.26%
- **计算**：1,311.56亿元 / 1,503.10亿元 ≈ 87.26%
- **解读**：每1元收入产生约0.87元经营现金流，对于重资产制造业而言属于极高水平。这反映了公司在产业链中的强势议价能力：对下游客户可能采用预收款或短账期模式（DRAM缺货背景），对上游供应商可能享有较长信用账期，营运资本管理效率突出。

#### （3）现金流增长与利润增长匹配度
- CFO同比增长+2,985.64%，远超营收增速+873.64%，体现了极强的经营杠杆效应。DRAM行业固定成本高，当产品价格突破盈亏平衡点后，增量收入几乎全部转化为现金流。管理层明确解释CFO大增主因“销售商品收到的现金增加”，与营收暴增逻辑一致，未见异常的非经营性现金流扰动。

#### （4）盈利纯度对现金流的保障
- 非经常性损益合计-11.88亿元（主要为金融资产公允价值变动损失），占归母净利润比例仅约1.5%，利润几乎全部来自主营业务。金融资产公允价值变动通常不影响CFO，因此现金流来源纯净、可靠。

## 二、 现金流高质量驱动的定性归因

### 2.1 行业景气与商业模式共振
- **供需缺口下的议价权**：2025年下半年以来全球DRAM供不应求，价格大幅上涨。公司作为中国第一、全球第四大DRAM厂商，充分受益于量价齐升。在缺货周期中，下游头部客户（阿里云、字节跳动、腾讯、联想、小米等）更倾向于预付或准时付款以保障供应，从源头上保障了回款质量。
- **IDM模式的规模效应兑现**：产能利用率保持高位运行，巨额固定成本被摊薄，边际现金流贡献率急剧上升。折旧等非付现成本在CFO中回加，使得经营现金流在景气周期中显著放大。

### 2.2 运营端精细化管理释放现金流
- **销售模式优化现金循环**：采用买断式经销与直销相结合的模式。买断式经销有助于快速实现产品和资金周转；与头部客户签订长期供货协议锁定需求，降低回款风险。两者结合使公司在高景气期最大化现金回流速度。
- **供应链管理增强议价能力**：建立了端到端的采购管理制度和严格的供应商绩效考核机制。在行业缺货背景下，公司对上游设备和材料厂商的议价能力增强，可能获得了更有利的信用账期，在营运资本层面释放了额外现金流。
- **外协模式调节现金流出节奏**：在封装、部分测试及模组环节采用外协加工，相比完全自建产线减少了当期购建固定资产的现金流出压力，使自由现金流在扩张期仍能保持相对韧性。
- **研发强度阶段性下降释放当期现金流**：研发投入占营收比例从上年同期的23.71%降至4.56%。虽然绝对额可能仍在增长，但占比的大幅下降意味着在营收爆发期，研发对经营现金流的消耗比例显著降低，进一步增厚了当期可支配现金流。需注意的是，这可能是阶段性现象，长期维持低研发强度可能影响技术迭代能力。

### 2.3 公司治理规范保障现金流安全
- 报告期内不存在控股股东非经营性占用资金及违规对外担保，公司治理规范，降低了现金流被体外循环或挪用的风险。
- 与关联方（如兆易创新等）的产业生态合作有利于业务协同，且未发现非市场化结算安排干扰经营性现金流。

## 三、 风险提示与关注要点

### 3.1 周期性风险是最大变量
当前卓越的现金流质量建立在“全球DRAM产品供不应求、价格大幅上涨”的基础上。DRAM行业具有显著周期性，若未来供需逆转、价格回落，CFO可能出现比利润更剧烈的收缩。报告中关于“供给紧缺格局延续”的判断属于前瞻性陈述，不构成承诺。投资者需密切关注2026年下半年及以后的合约价走势、宏观经济波动及地缘政治局势对实际现金流的潜在冲击。

### 3.2 高强度资本开支对自由现金流的压制
尽管当期CFO极佳，但作为全球第四大DRAM厂商，为维持技术迭代（第五代平台认证、LPDDR6量产）和市场份额扩张，未来仍需持续高强度资本开支（Capex）。高CFO能否覆盖高Capex从而产生正向自由现金流（FCF），是评估公司长期分红能力和偿债能力的关键。建议后续获取完整现金流量表后，重点测算FCF = CFO - Capex的真实水平。

### 3.3 研发强度下降的长期影响
研发占营收比从23.71%降至4.56%虽释放了当期现金流，但若长期维持较低研发强度，可能损害公司在下一代工艺技术平台和高端产品（如LPDDR6、HBM等）上的竞争力，进而影响未来现金流的可持续性。需关注公司后续研发投入是否随营收基数扩大而恢复合理强度。

### 3.4 数据局限性说明
本分析基于2026年半年度报告（未经审计）公开数据。由于缺少完整的资产负债表细项及现金流量表附注，暂无法精确计算应收账款周转天数（DSO）、存货周转天数（DIO）及自由现金流（FCF）。上述指标的补充将进一步提升分析的精确度。

## 四、 后续跟踪建议

1. **获取完整财务报表**：拆分“销售商品收到现金”与“购买商品支付现金”，精确测算营运资本变动方向，判断CFO高企是源于应收减少/预收增加（良性）还是应付大幅拖欠（潜在风险）。
2. **测算自由现金流（FCF）**：提取“购建固定资产、无形资产和其他长期资产支付的现金”科目，评估在高Capex下公司的真实可分配现金流水平。
3. **跟踪行业价格走势**：关注Q3/Q4 DRAM合约价及现货价走势，预判现金流拐点信号。
4. **同业对标分析**：对比三星电子、SK海力士、美光科技同期净现比、EBITDA Margin及FCF Yield，锚定长鑫科技在全球DRAM市场的相对竞争力位次。
5. **监测研发投入趋势**：跟踪下半年研发费用绝对额及占比变化，评估技术迭代能力的可持续性。
